# MYSTERY FILES — پرونده‌های مرموز

یک بازی داستانی تعاملی فارسی، با چند پرونده و انتخاب‌های چندمسیره.

## فایل‌ها
- `index.html` — صفحهٔ اصلی
- `styles.css` — ظاهر و طراحی
- `app.js` — داستان‌ها، گزینه‌ها، سرنخ‌ها و ذخیرهٔ پیشرفت

## اجرای محلی
فایل `index.html` را با Chrome، Edge یا Firefox باز کنید. برای نسخهٔ فعلی نصب پایتون یا سرور لازم نیست.

## آنلاین کردن با GitHub Pages (رایگان)
1. وارد GitHub شوید و یک repository جدید بسازید.
2. فایل‌های `index.html`، `styles.css` و `app.js` را در ریشهٔ repository بارگذاری کنید.
3. در repository به **Settings → Pages** بروید.
4. در بخش Build and deployment، گزینهٔ **Deploy from a branch** را انتخاب کنید.
5. branch را `main` و folder را `/(root)` انتخاب کنید و Save را بزنید.
6. پس از چند دقیقه، GitHub یک آدرس عمومی برای سایت نشان می‌دهد.

## آنلاین کردن با Netlify (رایگان برای سایت ایستا)
1. وارد Netlify شوید و یک سایت جدید از طریق روش deploy دستی بسازید.
2. پوشهٔ پروژه را به بخش deploy دستی بکشید و رها کنید.
3. Netlify یک آدرس عمومی می‌سازد.

## نکته‌ها
- این پروژه static است و به backend یا API نیاز ندارد.
- پیشرفت در مرورگر با `localStorage` ذخیره می‌شود؛ ذخیره‌ها بین دستگاه‌ها یا مرورگرهای مختلف همگام نمی‌شوند.
- داستان‌ها خیالی‌اند و هیچ دسترسی‌ای به فایل‌های واقعی رایانه ندارند.
